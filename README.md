# إدارة المخزون الذكي – V1.1

تطبيق ويب عربي RTL لإدارة مخزون البقالات والتموينات مع تنبؤات ذكية.

## الجديد في 1.1

- **قاعدة بيانات IndexedDB** (Dexie) بدل localStorage
- **بدون بيانات تجريبية** — تبدأ فارغًا
- تسوية المخزون (جرد)
- سجل حركات لكل منتج
- رسوم بيانية للمبيعات في التنبؤات
- صفحة الموردين
- مسودة / اعتماد / إلغاء أوامر الشراء
- تصدير واستيراد JSON

## التشغيل

```bash
cd inventory-app
npm install
npm run dev
```

افتح: http://localhost:3000

## البدء

1. أضف موردًا من «الموردون»
2. أضف منتجات من «المخزون»
3. سجّل مبيعات من «المبيعات»
4. راقب التنبؤات وأوامر الشراء

## العملة

الدينار الجزائري (د.ج / DZD)

## التقنيات

React · Vite · TanStack Router · Zustand · Dexie (IndexedDB) · Tailwind · Recharts · date-fns
